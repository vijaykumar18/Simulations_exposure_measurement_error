## Step 2 — Experiments

Three experiments repeat the same 10 scenarios with different error structures:

| Folder | Experiment | Error mean |
|--------|------------|------------|
| `exp_001` | E1 | Random only: v ~ N(0, σ²) |
| `exp_002` | E2 | Random + positive systematic: v ~ N(+0.25, σ²) |
| `exp_003` | E3 | Random + negative systematic: v ~ N(−0.25, σ²) |

**Scenarios** (same in each experiment):

| # | Error type | Association |
|---|-----------|-------------|
| 1 | Non-differential | Null |
| 2 | Non-differential | Harmful |
| 3 | Differential — less error in at-risk population | Null |
| 4 | Differential — more error in at-risk population | Null |
| 5 | Differential — less error in at-risk + 50% non-risk | Null |
| 6 | Differential — more error in at-risk + 50% non-risk | Null |
| 7 | Differential — less error in at-risk population | Harmful |
| 8 | Differential — more error in at-risk population | Harmful |
| 9 | Differential — less error in at-risk + 50% non-risk | Harmful |
| 10 | Differential — more error in at-risk + 50% non-risk | Harmful |

## Step 3 — Running Simulations

> Scripts must be run from **inside** the `exp_00X` folder, not the project root.

### Option A — All scenarios in one session

Estimated runtime: **10–12 hours** on Mac M2 with 16 GB RAM.

```bash
screen -S sims_all
cd ~/path/to/project/exp/exp_001
Rscript Sims_all.R
```

Detach: `Ctrl+A, D` — Reattach: `screen -r sims_all` — List: `screen -ls`

Repeat for `exp_002` and `exp_003`.

### Option B — Scenarios in parallel (~2.5 hrs total)

Run each `sims#.R` in its own screen session:

```bash
screen -S sims1
cd ~/path/to/project/exp/exp_001
Rscript sims1.R
```

Repeat for `sims2.R` through `sims10.R`.

### Option C — Parallel using shell script (~2.5 hrs total)

```bash
cd ~/path/to/project/exp/exp_001
chmod +x run_all_sims.sh   # first time only
./run_all_sims.sh           # creates 10 screens and runs each sims#.R
screen -ls                  # verify all screens are running
```

**Recommended order:** RStudio terminal screen sessions → HPC cluster → Direct R console
